Comece adicionando as prestações de contas

Os PDFs são lidos e processados dentro do seu navegador. Nenhum arquivo ou dado financeiro vai para o Git ou para a internet.

  1. 1. Localmente (com servidor): coloque os PDFs na pasta prestacao-de-contas/ e clique em ↻ Reprocessar.
  2. 2. Pelo navegador (ou GitHub Pages): clique em + Adicionar PDF abaixo ou arraste os arquivos PDF para qualquer ponto da página.
